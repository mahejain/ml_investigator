Evidence before answers

Understand what went wrong.

Bring a small machine-learning project and its run results. Explore plausible explanations, the evidence behind them, and a next experiment.

Start an investigation

Upload a ZIP with Python code, config and run logs. Files are read as text, never executed. Selected contents are sent to Nebius for analysis.

How it works

  • Finds relevant files and metric lines.
  • Uses Nemotron to build evidence-backed hypotheses.
  • Suggests a controlled follow-up experiment.
  • Uses Tavily to retrieve official documentation for the investigation when configured.

Model-generated explanations can be wrong. Check the cited evidence and avoid uploading secrets.
